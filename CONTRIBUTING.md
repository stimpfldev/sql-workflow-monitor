# Contributing

SqlWorkflowMonitor is proprietary, source-available software. This repository is published for technical evaluation, defect reporting, and selected collaboration. It is not an open-source license grant.

Before proposing a change:

1. Open an issue describing the defect or operational use case.
2. Do not include confidential information, secrets, customer data, sensitive credentials, or restricted artifacts.
3. Keep changes focused and preserve the on-premises deployment model.
4. Add a new numbered SQL script instead of rewriting a migration already included in a published release.
5. Run the public-repository verification and Release build.

Submission of an issue or pull request does not transfer ownership of the existing product and does not grant permission to use, copy, distribute, or commercialize SqlWorkflowMonitor outside the applicable license terms. Acceptance of external code may require a separate written contribution agreement.
